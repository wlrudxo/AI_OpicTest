# 모의시험 기능 범위

## 구현

- Background Survey 4단계와 69개 관심 항목, 난이도·회차 선택.
- 40분 모의시험, 7번 이후 난이도 조정, 문항별 녹음과 비동기 전사.
- 원본 음성·원본 전사 보존, 수동 전사 수정, 실패한 STT 재시도.
- 세션 복기, Markdown 내보내기, 외부 작성 피드백 표시.
- 설치 없는 브라우저 TTS와 영어 음성 선택.
- PC·모바일용 단일 HTML: 브라우저 STT, 결과 TXT·MD, HTTPS 정적 호스팅 지원.
- 주제 힌트 없는 회차 01–10 선택, 지정 관심 주제 조합의 자체 제작 10세트(15문항 기준 150자리), 문항별 유형 저장.

## 현재 제한

- 지정 관심 주제 조합은 고정 10회차를 사용하고, 다른 설문은 기존 템플릿을 순환한다. 장기 연습용 무작위 문제 생성이나 자동 AI 채점은 없다.
- 선택한 관심 주제에 따라 출제하며 직업·학생·주거 분기는 아직 출제에 적용하지 않는다.
- 타이머 일시정지, 답변 재녹음 비교, 공식 등급 판정은 구현하지 않는다.
- `feedback.json`은 표시만 하며 세션·답변 버전 검증은 후속 작업이다.
- GPU 로컬 앱은 단일 사용자 localhost 환경이다. 모바일은 별도 전달용 HTML을 HTTPS로 제공해야 한다. 호스팅 자동 배포와 실제 휴대폰 음성 검증은 포함하지 않는다.

## 후속 개선 후보

더 다양한 주제별 문제, 회차 생성, 피드백 스키마 검증, 재답변 비교를 검토할 수 있다. 현재 구현 또는 완료된 기능으로 표시하지 않는다.
