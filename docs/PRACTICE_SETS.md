# 설문별 자체 제작 모의고사 10회차

작성·검증일: 2026-09-17. 공식 기출문항이 아닌 자체 제작 연습문항이다.

## 적용 범위

회차 선택지는 01–10 숫자만 표시한다. 회차별 주제나 상황 이름으로 힌트를 주지 않는다. 실전 모드에서는 질문 텍스트를 숨기고, 복기에서는 주제·유형을 확인할 수 있다.

`practice_bank.py`의 10세트는 영화·공연·콘서트·공원·게임·독서·조깅·걷기·집 휴가·국내여행·해외여행을 모두 선택한 설문에 적용된다. 관심 항목을 추가해도 사용할 수 있다. `practice_bank_instrument.py`는 게임·독서 대신 악기 연주·헬스를 선택한 조합에 별도의 10세트를 제공한다. 특정 악기나 규칙적인 운동 습관을 가정하지 않는다. 두 조합을 모두 포함하면 기존 게임·독서 은행을 우선한다. 이 두 은행의 조건을 충족하지 않는 조합에는 기존 공통 템플릿을 적용하며 회차 4–10에서는 돌발·역할극 템플릿이 반복될 수 있다. 모든 설문 조합을 위한 고유 10세트를 완성한 것은 아니다.

선택 항목 중 ‘운동을 전혀 하지 않음’은 문제의 주제로 삼지 않는다. 조깅·걷기는 가벼운 활동을 전제로 하고 정기적 운동이나 전문 훈련을 가정하지 않는다. 직업·학교 생활을 강제로 전제하지 않는다. 공통 생활 주제는 설문 외 연습 범위로 함께 포함한다.

## 구성

- 기본 구성: 공통 자기소개 1 + 주제 묶음 3개×3 + 역할극 3 + 비교·논의 2 = 15.
- 각 은행에 총 150문항 자리. 자기소개 1개가 10번 반복되므로 고유 질문은 141개다. 그 외 질문 전문의 중복은 없다.
- 핵심 유형 T01–T14를 포함한다. T15–T16 확장 논증은 이번 세트에 추가하지 않았다.
- 난이도 1–2는 12문항으로 주제 묶음과 질문·문제해결 역할극까지 포함한다. 역할극의 상황과 수행 지시는 축약 시에도 유지한다.
- 난이도 6과 중간 난이도 조정은 같은 기본 문항의 설명 요구를 조절한다. 공식 출제 알고리즘이나 등급별 완전한 별도 문제은행이 아니다.
- 기존 저장된 세션은 질문을 다시 생성하지 않고 당시의 문항 스냅샷을 사용한다.

문항에는 유형 ID, 주제 ID, 관심/공통 구분, 묶음과 순서, 자체 제작 표시, 콘텐츠 ID와 버전이 들어간다. 실제 과제에 맞춰 유형을 개별 저장한다. 제작 근거는 [유형 조사](QUESTION_TYPE_RESEARCH_2026-09-17.md)를 참고한다.

## 질문 음성

2026-09-21부터 로컬 앱과 전달용 버전 모두 브라우저 기본 TTS를 사용한다. 별도 TTS 모델, WAV 캐시, MP3 사전 생성은 필요 없다. PLAY 버튼으로 영어 질문을 읽으며 기기가 제공하는 영어 음성을 선택할 수 있다. 음성 품질과 네트워크 필요 여부는 기기에 따라 다르다.

전달용 HTML은 프로필당 약 90KB, ZIP은 약 20KB이며 질문 텍스트 10회분을 포함한다. 기존 로컬 모델·음성 캐시는 더 이상 사용하지 않으며 사용자 데이터 폴더에서 자동 삭제하지 않는다.

## 확인한 내용

- 10세트의 개수·고유 질문·유형·관심 주제 커버리지.
- 모든 6개 난이도의 문항 수와 역할극 수행 지시 보존.
- 10회차 API 모델 허용 및 범위 밖 거절, 임시 폴더의 세션 저장·조회·난이도 조정.
- 기존 세션 문항을 조회할 때 다시 생성하지 않음.
- 전체 69개 설문 항목과 기존 선택 조합의 10회차 생성 호환성.
- 회차 선택지 숫자만 표시. 실제 마이크 녹음과 전체 150문항 청취 검증은 이번 변경 범위에 포함하지 않음.

## 저장된 설문 사용

시작 화면의 KT / SH 버튼은 개인 로컬 파일 `data/survey-presets.json`을 읽어 설문, 난이도 5, 01회차, 실전 모드를 미리 선택한다. 설문 원본은 Git에 포함하지 않는다. 각 단계를 확인하고 Next로 진행하며 회차는 01–10 중 고른다. 5–5 연습은 7번 뒤 “비슷한 수준으로”를 선택한다.

원본의 잘못된 수강 보기는 임의 변환하지 않는다. 수강 항목이 비어 있으면 최초 한 번 직접 고르고, 완료 시 해당 브라우저에 KT / SH별로 기억한다. 기록에는 선택한 프로필 ID를 함께 저장한다.

악기·헬스 은행 검증: `scripts/verify_instrument_bank.py`. 두 은행 모두 브라우저 TTS로 읽는다.
